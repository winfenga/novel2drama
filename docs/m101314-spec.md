## 1. M14 · 业务装配层（20 人日，8 子任务）—— 本批主轨

### 1.0 这一轨解决什么

盘上实测：28 个 MCP 工具只有 `echo` 一个注册；37 个 REST 端点只有 `/api/tools` + `/api/ping`；零持久化；`comfy/` `validate/` `shot/` `llm/` `promptlib/` `gpu/` 外部引用数**全为 0**。M14 的职责就是**把这些孤立模块接进 server**，不重实现任何业务逻辑。

### 1.1 核心架构决定 ⚖️

**一套实现，两套皮**（`api-contract.md` §6.4「一张表两套皮」的落地）：

```
apps/core/src/tools/handlers/xxx.ts   ← 业务实现（纯函数 + 依赖注入）
        │
        ├──► tools/index.ts  ──► defineTool(...)  ──► registry ──► /api/tools (MCP)
        └──► routes/xxx.ts   ──► Router          ──► app.use    (REST)
```

**REST 端点不是第二份实现**，是同一个 handler 的薄壳。REST 路由只做：取参 → 调 handler → 包 `ok()/err()` 包络。

### 2.2 核心签名（冻结）

```ts
// timeline.ts —— M10-1
export interface TimelineShot {
  shotId: string;
  shotCode: string;        // "SC-01"
  sceneCode: string;       // "SN-01"
  startSec: number;        // 全集绝对
  endSec: number;
  durationFrames: number;  // 交付帧率下的帧数
  videoPath: string;       // 相对 "video/SC-01.mp4"
}
export interface TimelineLine {
  dialogueLineId: string;
  text: string;
  speakerCode: string;     // "CH-01"
  globalStartSec: number;
  globalEndSec: number;
  shotIds: string[];       // 跨镜台词会有多个
}
export interface EpisodeTimeline {
  episodeId: string;
  /** 交付帧率 = deliveryFps(interpolateMul)，不是 24 写死 */
  fps: number;
  interpolateMul: number;
  totalDurationSec: number;
  totalFrames: number;
  shots: TimelineShot[];
  lines: TimelineLine[];
  audioPath: string;       // 全集连续一条
}
/** 输入按 shot.index 排序；算不出时抛 delivery_incomplete（绝不用 0.000 占位） */
export function buildTimeline(input: {
  episodeId: string;
  shots: { shotId: string; shotCode: string; sceneCode: string; durationSec: number; videoPath?: string }[];
  lines: { dialogueLineId: string; text: string; speakerCode: string; globalStartSec?: number; globalEndSec?: number; shotId?: string }[];
  audioPath: string;
  audioDurationSec?: number;
  interpolateMul: number;
}): EpisodeTimeline;
```

**关键规则**：
- `startSec` 是第一镜 0，之后 = 上一镜 `endSec`（**累加，不是各自从 0 起**）
- `durationFrames` = 该镜在**交付帧率**下的帧数。原 H3 帧数（17n+5 网格 @24）乘 `interpolateMul`（mul≤1 时乘 1）；**必须整除**，不整除抛 `delivery_incomplete` 说明哪一镜
- 缺口（有镜无视频 / 有台词无 global 时间 / 音频短于末镜 endSec）→ **整单抛 `delivery_incomplete`，details 列出每一处**，不跳过不占位

```ts
// fcpxml.ts —— M10-2
export function renderFcpxml(t: EpisodeTimeline, opts: { projectName: string; assetBaseUrl: string }): string;
```

FCPXML 硬约束（`api-contract.md` L1120-1157）：
1. `frameDuration="100/${fps*100}s"` —— **fps 跟随交付帧率**（24→`100/2400s`，48→`100/4800s`，96→`100/9600s`）
2. **时长用分数** `${frames}/${fps}s`，**绝不用小数秒**（`5.125s` 会在 24 镜后偏一帧）
3. `offset` 累加
4. **音频单独一条 lane**（`lane="-1"`）整条铺满，不切碎
5. XML 转义：`& < > " '` 全部转义；文件路径做 file URL 规范化（Windows 盘符 → `file:///D:/...`）

```ts
// srt.ts —— M10-3
export function renderSrt(t: EpisodeTimeline): string;
```
- 时间戳全集绝对，格式 `HH:MM:SS,mmm`
- **一条字幕 = 一句台词**，跨镜头的合并成一条（`shotIds.length > 1` 时不拆）
- 超 **20 字**用 `\N` 软换行（按句意断，不硬切）
- 无重叠、无空文本块

```ts
// csv.ts —— M10-4
export function renderCsv(t: EpisodeTimeline): string;
```

14 列，顺序固定：`shotId,shotCode,sceneCode,startSec,endSec,durationSec,videoFile,dialogue,dialogueStartSec,dialogueEndSec,voicedBy,taskType,chainSegment`
- `startSec/endSec` 三位小数
- `taskType` 小写
- `chainSegment` 单段填 1
- **UTF-8 with BOM**（`\uFEFF` 开头）
- 字段含逗号/引号/换行 → RFC4180 转义
