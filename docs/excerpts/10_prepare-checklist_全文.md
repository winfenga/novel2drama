# H3 素材准备清单

给用户看的「出词前要准备什么」。**按分支分别列出，只给用户当前那条分支的部分**，不要把几张表都塞过去。
每条都标明**必须 / 可选**；用户缺了「必须」项就明确说缺了没法做，缺「可选」项照常出词。

---

## 通用（四条分支每次都要列）

**必须**

- 画面里所有人都是 **18 岁以上**。有 18 岁以下幼童特征 → 直接礼貌拒绝，不进入流程。
- 只用你有权使用的素材。不要拿真实人物的照片做非自愿内容。

**给图的分支（I2VA / Ref2VA / Hybrid）还要满足**

- 图片清晰、人物的脸看得清、少遮挡（脸部被大面积遮住、糊、过曝都会影响人物绑定）。

**可选但建议**

- 画面内不要有水印、字幕、Logo、界面元素、可读文字。提示词末尾会声明排除这些，但源头干净效果更稳。
- 说明图里除主角外还有谁、那个人是什么角色（入镜互动 / 背景虚化 / 画外）。

---

## T2VA 分支要准备什么（文生视频）

**必须**

- **不需要任何图片或视频** —— 只给文字，模型从零构建画面。
- 一段**具体的文字设定**，至少说清：
  - 人物：年龄感、发型发色、瞳色、脸型气质、身材
  - 服装：款式、材质、颜色、配饰（若中途要脱，说明起始穿着）
  - 场景：室内 / 室外、什么空间、光线与时段、时代感
  - 动作与落点：从什么状态开始、做什么、结尾停在哪
- 目标时长：未指定按 **5 秒**；要改就给 **5–15 的整数秒**。

**T2VA 里不要放音频**

- T2VA 壳里**没有** `<Audio N>` / `<Video N>` 的位置 —— 想用**人物声线参考音频**必须改走 Ref2VA（见下方 Ref2VA 一节，只收声线、上限三条）。

**要先知道的两个代价**

- **没有图可锚定**：人物长相、服装、场景、画风全靠文字。描述含糊 → 每次出来的都不一样。
- 如果你对人物外形有明确要求（要"就是这个人"），**别走 T2VA** —— 改用 I2VA 或 Ref2VA 并给图。
- 就算给了图片 / 视频，**T2VA 里一条都不会被采用**（壳里没有参考标签的位置）。

**什么时候该换分支**

- 想让视频第一帧就是某张图 → **I2VA**
- 想锁住人物身份 / 服装 / 场景的一致性 → **Ref2VA**
- 既要第一帧就是某张图，又要锁住人物身份 / 服装 / 场景 → **Hybrid**（图与参考各至少一份）

> **★ 多参考连续链（硬性 · 2026-10-03 用户指定）**：要产出**多条**片段（多参考、多片段作品）时，**第 1 条走 Ref2VA、第 2 条起走 Hybrid** —— 第 2 条起把上一条的**实产尾帧**接成本条 `first_frame`，才保得住连贯（纯 Ref2VA 每条独立生成、第一帧不接帧，姿势／朝向／位置会漂）。**从第 2 条起要准备的就是「上一条的实产尾帧」这一张**（Hybrid 一节里列的关键帧）；没带就主动问一句「要不要接上一条的尾帧」，并提醒「不接会跳」。
>
> **★ 而且是一条一个来回（2026-10-03 用户指定）**：连续链**逐条串行出词** —— 出完 01 会**停下**，等你用 01 生成视频并把**尾帧**导出来给它，它才接着出 02。**不要指望它一次把 01–08 全给你**：后面条目的首帧得从前一条的尾帧来，前一条还没生成，它写不出真的接帧。你催「一起给」，它只会说明代价并让你二选一（串行 Hybrid 保连贯 ／ 批量纯 Ref2VA 不保接帧）。

## I2VA 分支要准备什么

**必须**

- **恰好一张**图，而且它**就是**你要视频从 **0.00 秒**开始的那一帧。视频第一帧长什么样，就是你给的这张图。
- 目标时长：未指定按 **5 秒**；要改就给 **5–15 的整数秒**。

**要提前知道的两个后果**

- 这张图同时锁定了人物、服装、场景、机位和画幅 —— 后面改不了，除非换图。
- **给多张图没用**：I2VA 只取一张，其余会被丢弃。要给多张就改用 Ref2VA。

**不需要准备**

- 音频、视频参考 —— I2VA 壳里没有 `<Audio N>` / `<Video N>` 的位置。

---

## Ref2VA 分支要准备什么

**必须**

- **至少一张**图。**一张纯人物图就够** —— 它提供身份与外观，不会被当成视频首帧。
- 目标时长：未指定按 **5 秒**；要改就给 **5–15 的整数秒**。

**可选（给得越多越可控）**

- 更多张图，每张说明它干什么用：

  | 图的角色 | 举例 |
  |---|---|
  | 人物主体 | 这张的脸、发型、身材 |
  | 服装 / 道具 | 这件衣服、这个项圈 |
  | 场景 / 构图 | 这个房间、这个机位 |
  | 动作 / 姿态 | 这个跪姿、这个角度 |
  | 关键帧 | 这张当作第 3 秒的画面 |

  > 不说明也行，会按画面实际内容自动判；但两张图在同一职责上冲突时（例如都当"场景"却是不同房间），会先来问你。

- **人物声线参考音频**（**只收这一种**）：用来把某个说话人的音色参考过去。**上限三条**（2026-10-01 用户指定，本技能自持硬规则）。要给就说明**这段声线属于谁**。
  - **不接受**：BGM、完整音轨、环境声、纯音效、纯乐器、节拍参考 —— 遇到会说明原因并拒收。
  - 保留值固定按 `audio reference` 处理（只参考音色，不搬音频信号）；参考音频里的原话**不会**被当成目标视频的台词。
- **视频参考**：剪辑源、续写起点、或只参考它的运镜与节奏。也要说明是哪种。

> **出词前必须问的一句**：要不要上传**人物声线**参考音频？（只收声线，不收 BGM／整轨）
> 选不需要 → 不加音频标签。选需要 → 上限三条；且**若当前是 T2VA / I2VA，必须改走 Ref2VA**（那两条壳里没有 `<Audio N>` 的位置）。

**数量与时长**

- 官方 Ref2VA 规范文本**未给出音频数量上限**；实际可用参数以 H3 界面 / 工作流为准。
- 分镜类技能里另有一条本地约定（最多 3 个音频、每个 2–15 秒、总时长不超过 15 秒），本路线不据此写死，仅供参考。

## Hybrid 分支要准备什么（关键帧 ＋ 参考混合）

**必须（两类缺一不可）**

- **① 一张关键帧**：明确指出它是视频 **0.00 秒的那一帧**（首帧）。想夹住结尾就再加一张**尾帧**。
  - 关键帧必须是**单张图片**，而且就是你想要的那一帧画面 —— 视频会从它内部启动，**第 0 帧不会换姿势 / 构图 / 视线 / 道具持握**。
  - **★ 多参考连续链的第 2 条起，这张关键帧默认就是「上一条的实产尾帧」**（见上方「什么时候该换分支」的连续链说明）—— 接上它才保得住与上一条的连贯。**这条尾帧要你先用上一条生成视频、再抽出来给它**；没抽出来之前，它不会往下出下一条。
- **② 至少一份参考素材**：另有参考图 / 参考音 / 参考视频，用来锁人物身份、服装、场景、姿态或声线。**只给关键帧、没有参考素材 → Hybrid 不成立。**
- 目标时长：未指定按 **5 秒**；要改就给 **5–15 的整数秒**。

**编号会怎么排（先知道，免得写提示词时对不上）**

| 你给了 | 关键帧 | `<Picture N>` |
|---|---|---|
| 首帧 ＋ 参考图 | `first_frame`（独立标识行） | `<Picture 1>` = 参考图①、`<Picture 2>` = 参考图②… |
| 首帧 ＋ 尾帧 ＋ 参考图 | `first_frame` ＋ `last_frame`（各一行） | `<Picture 1>` = 参考图①、`<Picture 2>` = 参考图②… |
| 尾帧 ＋ 参考图 | `last_frame`（独立标识行） | `<Picture 1>` = 参考图①、`<Picture 2>` = 参考图②… |

> **关键帧用字段名 `first_frame` / `last_frame` 独立标识、不占 `<Picture N>` 号**；`<Picture N>` 全部留给参考图，从 `<Picture 1>` 起按你给图的顺序排。**这点与纯 Ref2VA 一致**（第一张参考图就是 `<Picture 1>`），只是多了一行关键帧标识。

**可选（给得越多越可控）**

- 更多张参考图，每张说明它干什么用（人物主体 / 服装道具 / 场景构图 / 动作姿态）—— 「图的角色」表同下方 Ref2VA 一节。
- **人物声线参考音频**：规则与 Ref2VA 完全相同（**只收声线、上限三条**、保留值按 `audio reference` 处理）。
- **视频参考**：剪辑源 / 续写起点 / 只参考它的运镜与节奏。
- **尾帧**：可加可不加。**加了就必须让视频收在那一帧的构图上**。

**只给了一类素材时**

- 只给关键帧（没有参考素材）→ 实际等于 **I2VA**（**壳会变成「指令行 ＋ 三字段」**，不是六段）。
- 只给参考素材（没有关键帧）→ 实际等于 **Ref2VA**（六段壳，编号从参考图起算）。
- 两条都会先跟你说明代价，再由你决定：补上缺的那一类，还是降级走其中一条。

> Ref2VA 一节里的「数量与时长」「人物声线参考音频」规则在 Hybrid 下同样适用。

---

## 四条分支都要告诉我的信息

- **要不要人物声线参考音频**：出词前会被问一次 —— **要不要上传人物声线参考音频？**（**只收人物声线，上限三条**；选需要且当前是 T2VA／I2VA 时，会改走 **Hybrid** 或 **Ref2VA** —— 有明确关键帧走 Hybrid，没有则走 Ref2VA）
- **要演什么**：动作链与转折，以及**结尾落在哪**。
- **台词**：原话、谁说的、用什么称呼（默认中文）。
- **要不要配乐**：默认**没有**（`non_diegetic_music` 写 `N/A`）。
- 有没有**想避开**的套路（避免重复用过的叙事装置）。

---

## 参数不在提示词里设

**时长、分辨率、画幅都不写进提示词正文**，而是在提交给 H3 时设置。正文只用切点时间戳（`At 00:03.500, …`）和结尾落点来表达时长。

---

## 一句话版本（用户只想知道"给什么就行"时用）

> **给图**（推荐）：最少一张人物图就够，想更准再补服装 / 场景 / 姿态分开的图。
> **不给图**：那就走文生视频 —— 把人物、服装、场景、动作、结尾用文字写具体。
> **既要第一帧是某张图、又要锁身份**：走 **Hybrid** —— 一张首帧（可加尾帧）＋ 至少一份参考素材，两类都要给。
> 无论哪条：图和人都必须是 18 岁以上；再说清台词原话和结尾要落在哪。
