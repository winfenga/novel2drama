# 优秀案例库

## 管理规则

- **归属**：本文件由 `r18-novel-h3` 自持并管理，本技能四条输出壳（T2VA / I2VA / Ref2VA / Hybrid）共用它。案例 01-13 是历史 I2VA 设计素材，案例 14 起为 Ref2VA 六段格式案例（Hybrid 与 Ref2VA 同壳，直接复用）。
- **添加**：用户说“存入案例库 / 存案例 / 以后参考”时，把该轮**最终确认版**完整提示词追加为下一个案例（I2VA 存指令行 + 三字段 + 排除行；Ref2VA 存六段 + 排除行），自动生成简称（按主题 2-6 字，如「关门啪啪」「POV衣物」），并更新下方索引表。
- **调用**：用户说“用案例X / 按X案例写 / 要X那种效果”时，读取对应完整提示词，保留其叙事、镜头、声音与故事设计，把人物绑定 / 服装 / 场景重新绑定到当前参考图，再按新指令微调。
- **换壳**：调用的案例格式与目标路线不一致时必须换壳——旧 I2VA 案例改写成 Ref2VA 六段时，不得沿用 I2VA 指令行与三字段壳；Ref2VA 案例降为 I2VA 时同理。**目标路线是 Hybrid 时另有一步**：六段壳照用，但关键帧要按 `hybrid-rules.md` 改成字段名 `first_frame` / `last_frame` 独立标识、**不占 `<Picture N>` 号**，参考图则从 `<Picture 1>` 起重新连续编号；且不得把关键帧写成 `<Subject N>`。
- 只存最终可用的完整提示词，不存草稿。新增案例按用户“保存 / 加入案例库”指令触发；无指令不擅自追加。
- 案例库是**设计库，不是身份来源**：案例里的具名人物、服装、场景一律不得覆盖当前图片的实际内容。
