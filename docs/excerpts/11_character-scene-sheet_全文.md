# 人物／场景／时间线登记表（空白模板）

> **本文件是空白模板，不含任何具体作品内容。**
>
> **用法**：开新作品时，把本模板复制到**工作区** → `<工作区>/故事/设定.md`，再往里面填。填好的文件留在工作区。
>
> **从人物图起手时**：先按 `SKILL.md` 的「人物图 → 人物设定」让用户选 A（图推设定）／ B（只参考外表）两条路径，定好 `设定来源` 再填表。
>
> **硬性边界**：技能目录（`~/.workbuddy/skills/r18-novel-h3/`）是**只读模板库**。作品正文、角色设定、剧本内容、案例正文一律只落工作区，**不得写回技能目录**。这样多部作品各自独立，技能本身保持通用，可随时复制或分享而不带出任何私人内容。
