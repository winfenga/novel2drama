## 一、核心判断：NSFW 是一层内容策略，不是新流水线

那个压缩包拆开后是：

```
阶段 A/B/C：对话 → 成稿（产物就是一份 TXT 小说）
         ↓
阶段 D/F：出图
         ↓
阶段 E：TXT → 六段壳提示词
```

**「对话生稿」和「导入 TXT」产出的东西完全一样。** 后面全部共用同一条流水线。

| 组件                       | 通用性           |
| ------------------------ | ------------- |
| 剧本标准化（CF 事实台账）           | ✅ 100%        |
| 分镜规划（CSP / 时长级联 / 9 槽预算） | ✅ 100%        |
| 资产编号（SC/CH/PR）           | ✅ 100%        |
| 模型适配器（六段壳 / 四模块）         | ✅ 100%        |
| 质量门（20 项风险分、因果审计）        | ✅ 100%        |
| **R18 内容策略**             | ❌ **只有这一层专属** |

## 二、L0–L5 全档位

> 来源：`_原文摘录\02_qwen-i2i-nsfw-rules_全文.md` §3（原 L68–L86）

| 档      | 典型口语          | 可视状态定义                                |
| ------ | ------------- | ------------------------------------- |
| **L0** | 「色气一点」「有氛围」   | 服装不变，仅表情与环境：眼睑微垂、面颊泛红、唇部微启、光源转低位暖调    |
| **L1** | 「领口低一点」「露出肩膀」 | 服装完整，仅局部位移：领口下滑露锁骨与肩线、袖口滑落至肘          |
| **L2** | 「半脱」「衣服松一点」   | 仍挂着但结构错位：单侧肩带滑落、外层褪至腰际、解开数颗扣子，内衣仍在位   |
| **L3** | 「脱掉上衣」「只剩内衣」  | 指定衣物已离线或置于画面内，内衣仍在位，躯干大面积暴露           |
| **L4** | 「全裸」「不要衣服」    | 无衣物覆盖，可见范围由用户在使用时决定（是否用遮挡/角度收画面，不再作为档位定义强制） |
| **L5** | 「露出来」「细节特写」   | 全暴露，可见范围由用户点名的部位与景别决定         |

### 2.1 定档纪律（见 02 摘录 §3）

- 「再暴露一点」→ 相对**当前状态 +1 档**，写出目标档的可视状态
- 口语与档位冲突（说「全裸」但要「坐在客厅」）→ **档位优先，场景照写**
- **禁止保留口语程度词**（「一点」「稍微」「more」「a bit」「适度」），一律换成上表的可视状态
- **档位必须写满、写具体**：宁可铺满一档的状态描述，也不要「适度暴露」这类空转词

### 2.2 L5 的额外要求

L5 是「全暴露」，实现上要注意：

- **画幅要指定** —— 见 §六 画幅补充表（单人局部特写/器官细节 → `3:2` 或 `1:1`）
- **局部特写是 L5 的默认构图** —— 来源 `qwen-i2i-nsfw-rules.md` L137：「局部特写是达成器官细节需求的首选构图：景别收到局部、浅景深虚化其余部分，既提高细节密度，又天然回避大面积暴露」（是否采用由使用时判断，不再强制）
- **M5 四要素必须写全**：形态 → 位置 → 状态 → 光照与湿润度

## 三、M1–M5 五模块

> 来源：`_原文摘录\02_qwen-i2i-nsfw-rules_全文.md` §4（原 L90–L139）

| 模块                       | 管什么  | 核心写法                                      | 行号          |
| ------------------------ | ---- | ----------------------------------------- | ----------- |
| **M1** 裸露与服装状态           | 服装变更 | 服装项 → 变更动作 → 变更后物理状态 → 暴露区域 → 该区域光照与材质    | 原 L92–L99   |
| **M2** 亲密与性行为动作          | 接触点  | **四要素**：谁的哪个部位 → 接触谁的哪个部位 → 朝向与力度 → 造成的形变 | 原 L101–L110 |
| **M3** 题材元素（束缚/绳索/触手/兽人） | 几何   | **几何优先**：先写路径再有观感（路径 + 圈数 + 交叉点 + 张力）     | 原 L112–L117 |
| **M4** 氛围与神态             | 表情   | 写到**肌肉级**：眼睑开合度、视线落点、嘴唇开合、眉形、鼻翼           | 原 L119–L124 |
| **M5** 人体与器官细节           | 器官   | **四要素**：形态 → 位置 → 状态 → 光照与湿润度             | 原 L126–L139 |

### 3.1 各模块的关键纪律

**M1 · 三条硬要求**（原 L96–L99）

- 逐件点名，不用「衣服」统称。**输入图里存在的每一件都要有交代**（保留/移除/位移）
- **材质必写** —— 棉质吸汗、丝质贴肤反光、乳胶高光反射、湿透后透明度上升、针织延展变形
- 被移除的衣物**必须交代去向**（落在床沿/堆在地板/挂在椅背/滑至腰际），否则模型会让它凭空消失或残留
- 新暴露区域必须补**物理连贯性**：原被遮挡处皮肤光影连续、无接缝、无压痕残留

**M2 · 接触点锚定法**（原 L103–L110）

- 用解剖部位名，**不用「那里」「下面」这类指代**（模型解析不出指代关系）
- 交叠肢体必须写明**上下/前后关系**，否则会做出互为镜像的错误堆叠
- 手部：写明手指可见数量、抓握对象、掌心朝向。手是最常崩的部位，**必要时主动选择手不入镜或只露手背**
- 两个以上主体时**先分配固定指代**，后文全程沿用，禁止中途换称呼

**M3 · 几何优先**（原 L114–L117）

- 绳索写「缠绕路径 + 圈数 + 交叉点位置 + 张力」
- 触手写「数量 + 粗细梯度 + 根部起点 + 末端朝向 + 缠绕对象」
- 抽象形容词（「妖异」「淫靡」）**一律替换为几何与材质描述**
- **物理约束必写**：受压部位的组织形变、衣物被推移后的位置、结点处的局部褶皱
- 元素必须锚在画面已有物件或人物身上，**不允许凭空悬空**
- 多元素叠加时写清**遮挡与穿插的前后顺序**，否则会穿模

**M4 · 写到肌肉级**（原 L121–L124）

- 表情：眼睑开合度、视线方向与落点、嘴唇开合度与是否露齿或露舌、眉形变化、鼻翼
- 体表反应：潮红位置与扩散范围、薄汗位置与高光、发丝因湿润贴合脸颊
- **呼吸感通过躯干起伏与衣物形变间接表达，不要只写「喘息」**
- 与档位匹配：L0–L1 用细腻微表情；L3 以上神态须与暴露程度、姿态共同构成统一的身体语言

**M5 · 四要素**（原 L130–L137）

- **形态**：结构轮廓、比例、对称性、可见解剖细节
- **位置**：在画面中的坐标、朝向、与相邻部位的间距关系
- **状态**：充血/勃起与否、颜色深浅变化、是否被触碰或遮挡
- **光照与湿润度**：高光位置、湿度造成的镜面反射、皮肤次表面散射的通透感

### 4.1 各类的结构特点（用于结构化入库）

**① 脱衣类**（原 L342–L359）

按身体部位/衣物类型组织，每条是「动作 → 过程 → 结果」。01 摘录 §八·1 末尾另有**三条通用技法**（不绑定具体服装，可与任意条目组合）：

- **半挂中间态** —— 衣物褪到一半挂在手臂/腰间/脚踝，**半裸比全裸更勾人**
- **隔布触摸** —— 手掌滑入衣服内侧，布料逐渐被浸湿、贴出轮廓
- **高潮爆发** —— 高潮段把「缓缓」替换为「突然」

**② 展示类**（原 L361–L375）

按部位/动作组织（露乳、挤乳沟、揉乳、露背、露腰、露腿、露足、露臀、掀裙、M 腿打开、掰开、全裸展示）。

**③ 姿态类**（原 L377–L391）

> 用途：作为时间段落点、**定格姿态**，或位移模式的**终点状态**。全部为零柔韧门槛的日常诱惑姿态；**凡需要舞蹈/体操功底、需要他人托举的姿态一律不在本类**。

这条限制很重要 —— 姿态库的**准入门槛**是「单人可完成」。

**④ 实演类**（原 L393–L412）

**节奏总则**（L395，覆盖全局惯性）：

> 实演类是**有节奏的重复运动** —— 默认**中速、节奏分明、连续稳定**，从动作第一帧就进入节奏。
>
> 两个极端都禁止：一禁慵懒拖长的慢动作（H3 天然倾向舒缓慢镜，节奏词不写就会被拉慢），二禁密集急促的快速抽动（用力过猛会变成机械抖动）。也禁止「由慢到快」的渐变结构。
>
> 英文节奏词：`a steady, even rhythm` / `a moderate, rhythmic tempo` / `continuous rhythmic motions`，禁止 `slowly` / `gently` / `lingering`，也避免 `rapid` / `fast` / `furious`。

**⚠️ 「禁渐变」只管实演动作，不管神情和打斗 —— 定案**

规则看起来和 [分镜系统规则.md](./storyboard-rules.md) 的「B1 快慢交替」打架，实际是**对象不同**：

| 对象                 | 节奏规则                                   | 出处              |
| ------------------ | -------------------------------------- | --------------- |
| **实演类动作**（抽送等重复运动） | **中速稳定**，禁 `slowly`/`gently`，禁「由慢到快」渐变 | 本节              |
| **神情类**（表情与眼神）     | **要渐变**：清纯 → 迷离 → 淫媚，是状态转移链            | 本节 ⑥ 神情类        |
| **打斗动作**           | **要快慢交替**：短句连击 vs 长句慢蓄                 | 分镜系统规则 §10.1 B1 |

**「禁渐变」针对的是动作节奏，不是情绪推进。** 一条片子里，**动作从头中速稳定，情绪从清纯渐变到淫媚** —— 两者同时成立。

**执行**：写实演动作时用稳定节奏词；写表情时用渐变链；两者不在同一句话里混写。

**⑤ 互动类**（原 L414–L429）

按与镜头的互动方式组织（抛媚眼、勾手指、咬唇、舔唇、眨眼、凑近、膝行、回眸、歪头、指身体、拉腿展示、轻吻、托腮、吐舌比耶）。

**⑥ 神情类**（原 L431–L441）

**按情绪阶梯组织**，且最后一条是「渐变过程」：

> 眼神从清纯一点点染上迷离欲色 → 变成勾人的淫媚 → 最后媚眼如丝锁着镜头，瞳孔因情欲微微放大。

**这条是神情库的核心** —— 不是孤立表情，是**状态转移链**。

**⑦ 道具类**（原 L443–L459）

每条是「初始持有 → 动作 → 用途」的三段式，例如「书：原本捧着 → 合上放到一旁 → 开始脱衣」。

**⑧ 声音类**（原 L461–L469）

分五个子类：环境声、动作声、身体声、台词声、音乐。且标注了**归属规则**：

> 台词与同期声写进 `integrated_multimodal_description`；环境声、动作声、非语言人声汇总进 `overall_soundscape`；观众向配乐写进 `non_diegetic_music`。

### 4.2 位移模式（原 L473–L505）

**触发条件（唯一条件）**：故事弧中存在姿态/重心变化（坐→跪、站→俯身、躺→撑起、端坐→后仰、跪坐→分腿躺下）时启用。

> **原地小动作**（揉乳、解扣、舔唇、抛媚眼、托腮、揉阴蒂）**直接写，不触发位移写法**，更不要为小动作强行安排骨盆重组。

**三要素（从→到）**：骨盆 / 双腿 / 躯干。

**连续性**：上一秒端坐、下一秒躺平张开腿而中间没有下沉过程 = **姿态瞬移，禁止**。

01 摘录「位移模式」节末尾各有正确与错误示例。

## 五、状态梯度表（7 维 × 5 档）

> 来源：`_原文摘录\02_qwen-i2i-nsfw-rules_全文.md` §10（原 L259–L278）

| 维度       | 档 0   | 档 1      | 档 2       | 档 3            | 档 4                |
| -------- | ----- | -------- | --------- | -------------- | ------------------ |
| **湿润度**  | 干爽无光泽 | 微潮、无连续反光 | 表面泛柔和光泽   | 明显湿润、多处小高光     | 液体附着成膜、细长拉丝、局部滴落   |
| **充血色**  | 常态肤色  | 轻微泛红     | 明显红润      | 深红             | 紫红、充血肿胀            |
| **挺立度**  | 柔软下垂  | 半挺       | 挺立        | 高度挺立并上翘        | 高度挺立伴明显血管凸起        |
| **开合度**  | 闭合    | 微张       | 张开        | 明显张开并可见内部      | 大幅张开、结构充分外露        |
| **受压形变** | 无     | 轻微凹陷     | 明显凹陷、边缘微隆 | 深凹陷、周围组织堆积     | 深度凹陷并伴周边浅色勒痕       |
| **呼吸体表** | 平稳无反应 | 轻微起伏     | 明显起伏 + 薄汗 | 大幅起伏 + 大汗 + 潮红 | 剧烈起伏 + 大汗 + 局部肌肉颤抖 |
| **肌肉张力** | 放松    | 轻度收紧     | 明显绷紧      | 绷紧伴筋膜线条可见      | 强直收缩 + 颤抖          |

**使用纪律**（原 L273–L278）：

1. **每个维度只能选一档**，写成该档的具体可视描述，**禁止只写「湿润」「挺立」这类无强度词**
2. **跨维度档位应大致匹配** —— 「档 4 湿润」+「档 0 呼吸」= 矛盾指令，模型会折中处理
3. 与 L 档**独立**：L 管穿不穿，本表管身体什么样。可以「L 高 + 状态档中高」，也可以「L 低 + 状态档高」（隔着衣物）
4. **器官局部特写时通常推档 3–4**，特写放大后低档位会显得平淡

### 6.1 解剖术语对照表

## 八、同步整理：通用规范（SFW 也用）

`writing-conventions.md` 169 行里，**只有 3 条是 R18 的，其余 8 条全部通用**。

### 8.1 §10 台词密度 → 拆条（最重要）

> 来源：`_原文摘录\03_writing-conventions_全文.md` §10（原 L143–L169）

**核心结论**：

> H3 一条 15 秒最多 3–4 句台词。剧本一场戏常有 10–20 句，**这两条不冲突：不是删台词，是拆条。**

**落地机制**（原 L162–L169）：

- **先数台词，再定条数**：某段有 N 句台词 ⇒ 至少需要 `ceil(N / 3)` 条
- 原文自述踩坑：「把「一条 9 秒＝2–3 句」当成内容预算，为了塞得下就砍台词 —— **这是倒推，方向错了**」
- **正确方向：剧本是定数，条数与时长才是变量**
- 动作节拍同理：一场戏动作链一条 15 秒装不下，按「动作阶段」拆，不合并不跳过
- **核对方式**：交付前用剧本台词表逐句打勾 —— **成稿里出现过的每一句台词，都必须能在某一条提示词里找到**

**这条跟主人早就提的「台词冗余很长」是同一个问题的正解。**

### 8.2 §8 / §9 对白的双重校验（通用）

> 来源：`_原文摘录\03_writing-conventions_全文.md` §8/§9（原 L104–L141）

**§8 管「是谁在说」**（原 L104–L117）：先读人物设定；对白必须对得上年龄/身份/性格/口癖/关系/称呼；**称呼由人设决定、全篇统一**；用词层级随人设走，**不得所有角色说同一种话**；人设没定先问；**对白与设定冲突时以设定为准改对白**。


**§9 管「在哪说、什么时候说、说得出口吗」**（原 L119–L141）：

| 要素     | 影响什么                  |
| ------ | --------------------- |
| 时间     | 决定音量、体力状态、是否赶时间       |
| 地点     | 决定可用道具、可提的事物、回声与隔音    |
| 在场者与距离 | 父母在不在、隔几堵墙 —— 决定压不压声音 |
| 物理条件   | 隔音、水声、是否开灯、门开关        |
| 当前动作状态 | 决定台词长短与落点             |

硬约束：

> **隔一堵墙还大喊 = 违规。**  
> **场景里不存在的不能说，场景里存在的最好用上。**  
> **换地点必须重写对白。**

**⚠️ 台词的三级优先序 —— 定案**

三份资料各说一条，没有排出顺序。现在定了：

```
① 人设（谁在说）  ＞  ② 场景（在哪说）  ＞  ③ 故事弧模板（说什么类型的话）
```

| 冲突情形      | 怎么处理                                     |
| --------- | ---------------------------------------- |
| 人设 vs 场景  | **人设赢** —— 先定这个角色会怎么说，再按场景调音量与句长         |
| 场景 vs 弧模板 | **场景赢** —— 弧模板给的是「这段该说什么性质的话」，场景决定能不能说出口 |
| 人设 vs 弧模板 | **人设赢** —— 模板里的示例台词只是方向，不能套到角色身上         |

**举例**：一场「清纯→淫荡」的弧，房间里有睡着的父母。

- 弧模板说「第一次主动开口求欢」
- 场景约束说「必须压低、短、断续」
- **结果**：保留「主动求欢」的意图，但写成**气音 + 半句 + 顾虑动作**，不写露骨长句。

**依据**：`_原文摘录\03_writing-conventions_全文.md` §8/§9 是被用户反复修正后固化的约定，弧模板只是示例。**约束力：约定 ＞ 示例。**

**自查三问**（L141）：① 这个时间地点这些人，他说得出口吗？② 音量对不对？③ **这句话离得开这个场景吗**（换个场景也成立 ⇒ 写太泛了）？

### 8.3 §5 外形约束落进动作（通用）

> 来源：`_原文摘录\03_writing-conventions_全文.md` §5（原 L86–L91）

> **外形设定与动作必须自洽。** 已明确的外形特征，禁止写与之冲突的动作。
>
> 典型冲突：**短发角色禁止「手指插进头发」** —— 这个动作在物理上写不出来。

**这是「负面约束」思路** —— 正向写「她长发」不管用，必须明确禁止冲突动作。

### 8.4 脸红：**提示词层面不禁，改用定位式写法**

> 来源：`_原文摘录\03_writing-conventions_全文.md` §3（原 L71–L74）

原资料（**R18 小说正文**）要求：

> 禁用 blush、脸颊发烫、脸红到耳根。  
> **改用**：呼吸变化、眼神（半眯/失焦/避开）、嘴角动作（弯起/抿紧）、手指小动作（揪衣角/攥床单/指节发白）。

**理由成立，但只对小说成立** —— 脸红是廉价的情绪替代品，人读小说时不需要它。

**然而提示词是另一回事**：视频模型不靠「读者脑补」，它需要**具体的可见信号**。对模型说「用呼吸变化替代」等于没给信号。

### 定案

| 场景                | 规则                                                            |
| ----------------- | ------------------------------------------------------------- |
| **小说正文（入口 C 生稿）** | **禁脸红**，按原资料改用呼吸/眼神/嘴角/手指                                     |
| **视频提示词（渲染层）**    | **允许，但必须用定位式**：`耳尖→耳根→后颈`，写清扩散顺序与范围                           |
| **禁止的写法**         | `her cheeks flush` / `blush` / 笼统的「脸颊泛红」—— **无定位、无顺序的写法一律不用** |

**为什么这样定**：分镜系统规则的「脸红定位（耳尖→耳根→后颈，有顺序）」给的正是模型需要的东西 —— 一个**可执行的渐变路径**。原资料禁的是「模糊的笼统脸红」，不是「精确的血流扩散」。

**实测兜底**：如果模型渲染出来是高原红（整脸均匀发红），说明定位式也不管用，届时整条禁掉。**这个判断留给跑过片之后改。**

### 8.5 §4 禁重复句式 / §6 修正处理（通用）

- **§4**（原 L76–L84）：同一句式不得在相邻段落重复；每次重写前扫一遍前文
- **§6**（原 L93–L96）：被指出错误**当场认领并改**；**同一个问题被指出两次以上 → 写进规则文件**，下轮开始前自查

**§6 第二条是「规则自学习」机制** —— 反复出错的地方固化成规则。

**② 「台词空位」机制**

> 镜头逻辑按「门是否在正前方」分情况：
>
> - 门在机位正前方 → 镜头可**全程锁死不动**
> - 门不在正前方或画面没有门 → 镜头先**平滑跟随**，等门正对镜头/占满画面后再**锁死**

另两个通用技巧：

- **破「人物僵住」锚点的手段按图决定**：图里有人拿手机 → 手机脱手掉地；没有 → 写伸手抓门框落空、身体扭动踉跄
- **门关满画面后只写声音**，不写任何动作画面

**第三条省钱又有效** —— 画外音效替代画面。

### 12.1 虚拟角色与幼态的判定口径（2026-11-10 用户裁决，覆盖原措辞）

**背景**：虚拟创作存在「几百岁的少女 / 千年狐妖 / 吸血鬼」等设定——外表年轻但设定为成年。原措辞（「幼态特征」「年龄无法确认」）容易把这类角色误拦截；同时**幼态 NSFW 是绝对红线，任何时候都不允许**，口径放宽不能碰到这条线。

**裁决：按「身体呈现」判，不按「设定数字」判，两条线分开**：

| 判定 | 标准 | 结果 |
|---|---|---|
| **硬拒（任何情况下不放行）** | 儿童身体特征：头身比偏幼、四肢短粗、第二性征未发育、呈现为儿童的身体；或明确的**未成年身份指向**（小学生/中学生/儿童/幼等身份词，或「校园 + 义务教育年龄段」的明确语境，如「初中教室里」「十四岁的学生」） | 直接拒绝，退 SFW 非性化编辑。「外表是小孩子」的虚拟角色不管设定几百岁都不行——**身体是儿童的，就没有 NSFW** |
| **不作为拒绝依据** | 单纯的「外表年轻」：年轻面容、娇小体型（非儿童比例）、二次元大眼画风、设定数字（「五百岁」「千年」）、「少女」等称呼词；**服装品类词（JK 制服、百褶裙、水手服、学院风等）**——JK 在当代语境已泛化为时尚品类，服装不构成身份证据 | 这些**不构成拦截理由**。几百岁的少女设定只要身体呈现是成年人体（成熟体型、第二性征发育），正常过闸。**成年身体 + JK 制服 = 放行**；服装只在与其他未成年信号**叠加**时作为佐证（如「初中教室里穿校服的学生」这种身份+场景组合） |
| **无法确认时** | 图片/文本既无儿童身体特征、也无成年特征可依（画风极端风格化、信息不足） | **按可判定的证据走**：有任一未成年身体信号 → 拒；完全没有未成年信号且上下文指向成年（成熟体型/成人语境）→ 过。原「年龄无法确认为成年 → 拒」的一刀切改为：**只在存在未成年信号或儿童身体特征时拒**，纯风格化画风不算信号 |

**为什么这样分**：原闸门拦的是「未成年特征」，不是「年轻」。误拦截的根因是把「年轻/娇小/二次元画风」混进了「幼态」的判定集。修正后判定集收窄到**儿童身体特征与未成年身份语境**，「几百岁的少女」这类成年虚拟角色不再被「少女」「年轻」字面误伤；而「外表是小孩子」的角色无论设定多少岁都拦——**判身体，不判户口**。

**实现要求**（在原四条之上追加）：

5. **判定集收窄** —— 拦截只依据：儿童身体特征（头身比/四肢比例/第二性征）、明确的未成年身份指向（小学生/中学生/儿童/幼 + 义务教育语境）、明确自报年龄数字 < 18。外表年轻、娇小、风格化画风、**非未成年的设定数字（如「五百岁」）**、称呼词、**服装品类词（JK/百褶裙/水手服）**不进判定集
6. **双信号相乘** —— 文本设定（几百岁）与视觉呈现（身体特征）冲突时，**以身体呈现为准**；两者都指向成年才过闸
7. **误拦截可申诉** —— GUI 提供人工复核入口：用户可对拦截结果申诉，复核时由用户补充设定材料（人设档案/全身立绘），**复核通过的标准依然是身体呈现，不是设定数字**——申诉改变的是「证据充分度」，不是判定标准本身
