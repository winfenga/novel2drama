## [001] 2026-11-10 23:55 · M10-1 · 全集绝对时间轴

- **做了什么**：`buildTimeline()` 落地：镜头按输入顺序累加，第 1 镜 0、第 N 镜 = 上一镜 endSec；
  `durationFrames` 按**交付帧率**算；缺口一次性收集后整单抛 `delivery_incomplete`。
- **改了哪些文件**：
  - 新增 `apps/core/src/delivery/timeline.ts`
- **关键决定**：
  1. **物理时长 = 生成帧数 / 24**，不用 `durationSec` 直接累加。理由：`secondsToFrames()` 走 17n+5 网格
     （5s→124 帧 = 5.1667s），真实出片就是 124 帧；若按输入秒数累加，FCPXML 的帧号会和视频实际帧数对不上。
     插帧是「帧数×mul、帧率×mul」，物理时长不变，所以恒用 `GENERATION_FPS` 换算。
  2. 所有缺口**先收集再抛**（不是遇到第一个就 throw），`details.gaps[].kind` 分 9 类，
     每类都带 `shotCode` / `dialogueLineId`，满足「details 列出每一处」。
  3. 台词 `shotIds` = 显式 `shotId` ∪ 时间区间重叠到的镜头 → 跨镜台词自然有多个，下游 SRT 因此不会拆句。
- **踩到的坑**：
  - `noUncheckedIndexedAccess` 开着，数组索引全是 `T | undefined`，`shots[shots.length-1]` 要显式判空。
  - 台词区间含端点会在镜头接缝处误命中两镜，比较时加 `1e-9` 消抖。
- **验证**：`npx tsc --noEmit` → 0 error。（测试稍后与 M10-2~7 一起补）
- **下一步**：M10-2 FCPXML。

## [002] 2026-11-10 23:58 · M10-2 · FCPXML（分数时长 + 音频单 lane）

- **做了什么**：`renderFcpxml()`：`frameDuration="100/${fps*100}s"` 跟随交付帧率；每镜时长
  `${frames}/${fps}s` 分数；`offset` 逐镜累加；音频一条 `lane="-1"` 的 `asset-clip` 铺满；
  `escapeXml()` + `toFileUrl()` 处理五实体与 Windows 路径。
- **改了哪些文件**：
  - 新增 `apps/core/src/delivery/fcpxml.ts`
- **关键决定**：
  1. **不约分**。`124/24s` 不化成 `31/6s`——契约要求「duration 分母统一」，约分后分母就不统一了，
     而且 precheck 第 6 项正是靠分母认帧率。
  2. `offset` 用**帧号整数累加**再转分数，不用秒浮点累加（否则第 24 镜就漂一帧）。
  3. 路径只编码 `% 空格 # ?`，中文保留原始 UTF-8。全量百分号编码会让 paths 不可人工核对，
     而 FCPXML 本身是 UTF-8，FCP/剪映都吃得下。
  4. 素材根同时接受 `file:///...` 和 Windows 绝对路径（`D:\...` → `file:///D:/...`）。
- **踩到的坑**：相对 import 都在同目录，不涉及 `../` 层级；`verbatimModuleSyntax` 下
  `import type` 与值 import 要分开写。
- **验证**：`npx tsc --noEmit` → 0 error。
- **下一步**：M10-3 SRT。

## [003] 2026-11-10 00:05 · M10-3 · SRT（一句一台词，跨镜合并）

- **做了什么**：`renderSrt()` + `buildSrtBlocks()` + `wrapSubtitle()` + `formatSrtTime()`。
  时间戳即全集绝对时间（`HH:MM:SS,mmm`）；一条台词一块、跨镜不拆；超 20 字用 `\N`。
- **改了哪些文件**：
  - 新增 `apps/core/src/delivery/srt.ts`
- **关键决定**：
  1. **折行先按标点切句，再按目标宽度装行**：行数 = `ceil(len/20)`，目标宽度 = 均分后的宽度，
     这样 21 字切成 11+10 而不是 20+1（避免孤字行）。断点落在 `，。！？、；：…—` 之后。
  2. 无标点的长串只能硬断（中文没空格可切），这是唯一确定性做法，不是降级。
  3. 块尾截断到下一块起点（`endMs = min(endMs, nextStartMs)`）——字幕重叠在播放器里会闪字，
     契约第 7 项要求「无重叠」。截断后 `end<=start` 直接抛错，不留退化块。
- **踩到的坑**：第一版 `wrapSubtitle` 的 while 条件写错了（`out.length < maxLines-1` 分支永真），
  21 字会切成逐字一行；改成「按句段贪心 + 目标宽度」后干净了。
- **验证**：`npx tsc --noEmit` → 0 error。
- **下一步**：M10-4 CSV。
