## [001] 2026-11-10 20:45 · M06-1~M06-8 · 分镜引擎八件套全部落地

- **做了什么**：M6 全部 8 个子任务一次完成——
  - M6-1 `cascade.ts`：九公式逐项照 storyboard-rules §四（时间码累积 / ceil(D/Mmax) 子镜 / floor(D×2.5) 台词建议 / floor(D×3) 硬上限 / min(9,round(D×0.6)) 槽 / ceil(D/4) 节拍 / 运镜 1+2 / 表情 [1,3] / maxFaces=3）；D 非 5-15 整数抛 `DramaError("invalid_param")`
  - M6-2 `dialogueBudget.ts`：超建议值→extend 建议（targetD=ceil(N/2.5)，>15 则 split）；超硬上限→split 两镜；绝不静默压缩台词；`minLineCount=ceil(N/3)`
  - M6-3 `slots.ts`：`planSlots` 槽预算+节拍区间（D 内均分），超槽只标 over 不裁内容（E5：通用 9 槽）
  - M6-4 `initialPosition.ts`：E3——只做数据结构+规则校验器（非空、方位词表、ASCII `@XX-NN` 标记解析）；CF 重建留 M3/M5
  - M6-5 `assetCodes.ts`：SC/CH/PR-两位数，按首次出现顺序、人物/场景先道具后；同资产二次出现不重分配；变体 -A/-B/-C；D4 `pickAssetBoardTemplate`（默认 C，realistic→A，永不 B）；D5 `sceneAnchorLayout` 60/20/20
  - M6-6 `riskScore.ts`：三闸 5+8+7 分组；闸一③④、闸二全 8 项、闸三⑭⑮⑯纯规则；E4——①②⑤⑰-⑳ 返回 score:1 + "待 LLM 接入"；`shouldProceed` 承载闸间单向流水
  - M6-7 `causality.ts`：六节点/六关系/边结构照 spec；断链（端点缺失/动作无出边/indirect 缺上游/无证据/prevEndState 未衔接）与反事实冗余双清单，与风险分完全独立
  - M6-8 `triggers.ts`：冻结映射逐条 duration→[6,8,9,10,12] / dialogue→[9,13]+audioStale / asset→[13,19] / character→[3,4,19]
- **改了哪些文件**：
  - 新增 `apps/core/src/shot/{cascade,dialogueBudget,slots,initialPosition,assetCodes,riskScore,causality,triggers}.ts` + 各自 `.test.ts`（16 文件）
  - 新增 `apps/core/test/shot.test.ts`（聚合入口，见踩坑①）
- **关键决定**：
  1. vitest 配置只收集 `test/**` 且配置文件冻结——加 `test/shot.test.ts` 聚合入口 import 全部 src/shot 套件，不改既有文件、不动 spec 冻结位置
