## [004] 2026-11-10 18:44 · [CORRECTION #1] 修正 [003] 的 `DramaPaths` 四字段结构

- **关键决定**：
  1. **损坏 ≠ 缺失**：配置文件不存在才回退/建默认；JSON 坏或结构非法**直接抛**——静默重置等于抹掉用户 Key。
  2. **legacy 读到不落盘**：旧配置只读，用户显式改配置时才写新目录，避免与旧文件被外部编辑产生分叉。
  3. **guard 五步顺序的安全理由**：跨站判定在取凭据之前（403 不泄漏 token 对错）；先凭据后 Origin（防攻击者靠 401/403 差异探测白名单）；`x-drama-source` 最后（审计标签不影响安全判定）。
