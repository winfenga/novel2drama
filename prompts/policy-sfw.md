# Policy · SFW（通用内容策略）

> 适用：`mode = sfw`。表演描述、神情渐变、介质措辞为通用规范；负面词 ①②③⑤⑥——**④（器官与接触）整类删除是 SFW 裁剪纪律**（nsfw-design §10.1）。

## 1. 表演描述规范（通用）

- 动作写法只写「谁→做什么→对谁→结果→必要声音/物理反馈」，一镜一核心事件；写「动作段」不写「人体运动学」。
- **禁空泛副词**：极具力量感地 / 帅气地 / 迅猛无比 / 如鬼魅——必须换成具体动作与可见结果。
- **实演节奏总则**（动作类通用）：默认中速、节奏分明、连续稳定，从动作第一帧就进入节奏。英文节奏词白名单：`a steady, even rhythm` / `a moderate, rhythmic tempo` / `continuous rhythmic motions`；禁 `slowly` / `gently` / `lingering`，避免 `rapid` / `fast` / `furious`。
- **「禁渐变」只管动作节奏，不管神情**：动作从头中速稳定；情绪（神情）按 §2 渐变链推进。两者不在同一句话里混写。
- **位移三要素**（骨盆/双腿/躯干 从→到）：存在姿态/重心变化时启用；原地小动作直接写，不为小动作强行安排位移；禁止姿态瞬移（中间过程缺失）。
- **外形约束落进动作**：外形设定与动作必须自洽，禁止写冲突动作（短发角色禁止「手指插进头发」）。
- **脸红：定位式写法**（提示词层面允许）：必须写扩散顺序与范围——`耳尖→耳根→后颈`（ear tips → ear rims → nape）；**禁止** `her cheeks flush` / `blush` / 笼统的「脸颊泛红」这类无定位无顺序的写法。
- **群像焦点**：当前焦点是谁就拍谁；镜外人物不写动作不点名；反应/表情只给当前在焦人物。

## 2. 神情渐变（通用版）

- 神情是**状态转移链**，不是孤立表情：眼神从清纯一点点染上迷离欲色 → 变成勾人的淫媚 → 最后媚眼如丝锁着镜头（SFW 场景下调降为：平静 → 注意 → 动容 → 决意/羞涩/释然，按剧情弧选链）。
- **写到肌肉级**：眼睑开合度、视线方向与落点、嘴唇开合度与是否露齿、眉形变化、鼻翼张合。
- 体表反应：潮红位置与扩散范围（定位式）、薄汗位置与高光、发丝因湿润贴合脸颊。
- **呼吸感通过躯干起伏与衣物形变间接表达，不要只写「喘息」**。
- 每次重写前扫一遍前文：同一句式不得在相邻段落重复。

## 3. 分介质措辞（通用，SFW 也要）

> 介质一致性是硬约束：最常见的翻车是「动漫角色被写成写实人体」，会直接导致面部漂移。

| 介质 | 靠什么表现 | 该写什么 | 禁止写 |
|---|---|---|---|
| **anime / 二次元** | 线条与色块 | 线条粗细走向、色块分层（明暗两段）、高光块形状、边缘线处理 | 皮肤纹理、毛孔 |
| **2.5D / 半写实** | 结构较真但肤质简化 | 结构准确 + 简化肤质，体积转折与柔光 | — |
| **realistic photography** | 肤质与光学 | 次表面散射透光、毛孔汗毛、皮下血管、镜面高光、湿度真实反射 | 线条、色块 |
| **illustration / painting** | 笔触与色彩关系 | 笔触方向、冷暖对比、色彩过渡、边缘虚实 | — |

## 4. 负面词 ①②③⑤⑥

> 写法硬约束：短语列表（逗号分隔名词短语，不是句子），单段无换行；与正向同语言；**不写否定词**（直接写「多余手指」，不写「没有多余手指」）；不与正向重复；按介质取词（介质漂移词必须与目标介质相反）。

- **① 介质漂移**（防跑成别的画风）：anime 任务：`3D渲染` `CG渲染` `写实摄影` `半写实` `欧美厚涂` `油画笔触` `写实皮肤纹理` `毛孔`；realistic 任务：`线条描边` `平涂色块` `卡通描边` `赛璐璐上色` `二次元`
- **② 手部崩坏**（最高频崩点；**构图已排除手部（手不入镜）时 ② 仍保留**——它是防手部误入镜的那道闸）：`多余手指` `六指` `手指融合` `爪状手` `畸形手` `手部糊连` `断裂手指` `手掌穿模` `手部与身体黏连`
- **③ 肢体结构**（防多肢与穿模）：`多余肢体` `多余的手臂` `多余的腿` `肢体融合` `肢体穿插` `镜像错位` `缺失肢体` `断肢`
- **⑤ 面部与身份**（防脸崩；SFW 语境下不含 R18 专属词）：`面部崩坏` `换脸` `五官错位` `双眼不对称` `瞳孔异色` `脖子过长` `头身比失衡` `手过大` `肤色断层`
- **⑥ 画面技术**（防工程痕迹）：`低分辨率` `模糊` `噪点` `过度锐化` `锯齿` `拼接痕迹` `接缝` `色带` `水印` `签名` `文字` `logo` `边框` `黑边`

**④ 器官与接触（`畸形生殖器` `器官错位` `器官缺失` `插入关系断裂` `接触点悬空` `色块界限错位`）在本文件中整类不存在——SFW 任务删掉 ④ 整类是既定裁剪纪律**（nsfw-design §10.1：SFW ❌ / NSFW ✅）。NSFW 版见 policy-nsfw.md。

裁剪纪律：六个类不必每类都出词，但**至少要覆盖 ①③⑥**（介质漂移 + 肢体 + 工程痕迹是通用崩坏面）。
