# 词汇修正表（AI 腔 → 人话）

> 来源：`docs/excerpts/15_TK写作SKILL_全文.txt` L168-178。
> 用途：`polish` 阶段逐句过表；`apps/core/src/novel/glossary.ts` 的 `WORD_FIXES` / `BANNED_WORDS`
> 是本表的可执行副本，改表必须两边同步（以本文件为人类可读权威）。

**核心原则**：拒绝「AI 腔」，使用符合中文网文习惯的自然表达。

## 1. 替换表

| 禁用 / 避讳（AI 常用） | 推荐替换 | 说明 |
|---|---|---|
| 感官风暴 | 快感风暴、极乐洪流 | 「感官」过于学术，不够色气 |
| 丢了 / 掉了 | 去了、绝顶、登顶、崩坏 | 机翻感严重的错误表达 |
| 娇躯、娇喘（过度使用） | 胴体、玉体、甜腻的呻吟 | 避免词汇贫乏，按情境多样化 |
| 某种、某种程度的 | 具体描述 | 模糊词汇，直接写具体的生理感受 |
| 仿佛、似乎（过度使用） | 肯定句式 | 增强临场感，减少不确定修饰 |

## 2. 判定口径

- **「过度使用」不等于禁用**：同一词在 500 字内出现 2 次以上才判违规。
- **替换要贴情境**：`去了 / 绝顶 / 登顶 / 崩坏` 不是同义词自由互换——按强度递进选用，同一场景内不重复同一档。
- **肯定句式改造**：`仿佛`/`似乎` 保留在「视角人物真的不确定」处；用于规避描写的地方一律改实写。
- **不得为了贴表把语义改掉**：修的是表达，不是情节。

## 3. 与其它段的关系

- 本表只管**词汇**；句长节奏、符号与括号用法见 `punctuation.md`（S5 主段）。
- 描写层是否合格见 `conventions.md`（S2）的自检清单。
- `novel.kb` 第 5 章的 `banned` / `preferred` 优先级**高于本表**（用户自定义胜过通用规范）。
