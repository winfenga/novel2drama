# S5 · 括号类标点校对规范（punctuation_brackets）

> 来源：`docs/excerpts/15_TK写作SKILL_全文.txt` L1261-1446（S5 段）。
> 本文件只承载 **S5 = 括号类标点与心形符号的检测/修正规则**。
> 词汇替换见 `glossary.md`；描写层规范见 `conventions.md`（S2）。

**唯一目的**：在不修改任何文字内容的前提下，仅修正括号类标点与心形符号。

**严格禁止**：
- 修改任何对话台词 / 旁白叙事句子的文字内容
- 增删任何剧情内容，改变任何人物行为描写
- 对文本润色、扩写、改写

**仅允许**：替换括号类标点（`「」` `『』` `【】` `（）` `""`）、替换心形符号（`♡` ↔ `❤`）、删除 `」`/`』` 前多余的句号（`。`）。

## 1. 符号语义基准

| 符号 | 语义 | 判断依据 |
|:---:|---|---|
| `「」` | 常规对话 / 对手戏甲方（主动方、调教者） | 主要角色的所有发言，无论音量大小；对手戏中为主导方 |
| `『』` | 对手戏乙方（被动方、被调教者）/ 特定名词引用 | 对手戏中为承受方；或引用世界观专有名词 |
| `【】` | 机械语音 / 系统广播 / 公告提示 | 说话来源为非人类（装置、系统、广播） |
| `（）` | 心理活动 / 内心独白 / 潜意识 | 角色未说出口的想法、情绪、判断 |
| `""` | 路人对话 / 背景人物发言 | 非主要角色（路人、旁观者、过路人） |
| `❤` | 快感符号（甲方）/ 色气语调装饰（主动方） | NSFW 场景中主动方的快感表达 |
| `♡` | 快感符号（乙方）/ 色气语调装饰（被动方） | NSFW 场景中被动方的快感表达 |

## 2. 规则清单 R1-R8

### R1 句号省略
- **检测**：`」` 或 `』` 前存在句号 `。`
- **修正**：删除该句号
- **示例**：`「我知道了。」` → `「我知道了」`；`『不要这样。』` → `『不要这样』`

### R2 情感标点保留
- **检测**：`」`/`』` 前的 `！`、`？`、`……`、`～`
- **修正**：**不得删除，保持原样**
- **示例**：`「不行了！」`（保留）；`『不……不要……！』`（省略号+感叹号都保留）
- **与 R1 的组合**：`「不行了。」` → `「不行了」`；`「不行了！」` → 原样；`「不行了。！」` → `「不行了！」`（句号删、感叹号留）

### R3 对手戏符号区分
- **检测**：两位主要角色交替对话但均用 `「」`
- **修正**：甲方保留 `「」`，乙方改 `『』`
- **示例**：`「你还撑得住吗？」` + `「撑……撑得住……！」` → 后者改 `『…』`

### R4 路人符号区分
- **检测**：非主要角色用 `「」` 发言
- **修正**：改 `""`
- **示例**：走廊里传来的问话 → `"里面好像有点吵……"`

### R5 心理活动符号
- **检测**：心理活动/内心独白混写在旁白里、未用 `（）` 包裹
- **修正**：用 `（）` 包裹
- **示例**：`她心想，为什么身体会有这种反应。` → `（为什么……身体会有这种反应……）`

### R6 系统/机械语音符号
- **检测**：机械装置、系统提示、广播公告使用 `「」` 或其他符号
- **修正**：改 `【】`
- **示例**：`「检测到异常，请保持静止。」` → `【检测到异常，请保持静止】`

### R7 低声细语符号
- **检测**：描述为「小声」「低声」「嘟囔」「窃窃私语」的**主要角色**发言
- **修正**：保留 `「」`，不做修改
- **注意**：`""` 只用于**非主要角色**，不因音量小而改符号

### R8 心形符号对手戏区分
- **适用**：NSFW 小说中用 `♡` / `❤` 表示快感或色气语调
- **检测**：对手戏中甲乙双方用同一种心形符号
- **修正**：甲方统一 `❤`，乙方统一 `♡`（与 `decision-log §十八` 编码裁决一致）
- **非对手戏**：单角色独白或旁白中的 `♡`/`❤` 保持原样，不区分

## 3. 执行顺序与优先级

```
扫描全部规则 → 标记违规 → 按优先级应用修正
优先级：R6（系统）> R3（对手戏）> R8（心形）> R4（路人）> R7（低声）> R5（心理）> R1（句号）> R2（保留确认）
```

先判定说话来源与角色身份，再动括号；R2 永远是最后一道确认，防止情感标点被误删。

## 4. 输出格式

- 只输出修正后的完整文本，**不加任何说明、表格、统计或注释**。
- 无需修正时仅输出原文，同样不加说明。
- 代码侧对应实现：`apps/core/src/novel/glossary.ts` 的 `checkPunctuation(text)`，返回 `{ line, message }[]`，**只报不改**。

## 5. 对手戏角色判断（按优先级）

1. **明确身份标注**：上下文有「调教者/被调教者」「主人/宠物」等称谓
2. **行为语义**：发出指令、提问、嘲弄 → 甲方；回应、求饶、承受 → 乙方
3. **语气强弱**：语气强势、完整句 → 甲方；断续、带拟声、求饶 → 乙方
4. **叙事视角**：有明确主视角时，主视角通常为甲方
5. **无法判断**：保持原符号不变，不做修改（**不许猜**）
