## 1. 深度交织公式（每段必过）

```
[调教者行为] → [被调教者生理反馈] → [破碎的言语/拟声] → [心理/第三方视角]
```

四层**缺一即判不合格**：只有动作堆叠 = 廉价化；只有心理 = 空洞；只有拟声 = 噪声。

| 层 | 必须包含 | 反例（判不合格） |
|---|---|---|
| ① 调教者行为 | 动作 + 背后的神态与意图（戏谑眼神 / 指尖轻佻划过 / 掌控欲的力度）；快慢结合的节奏感 | 只写「他按下了开关」 |
| ② 生理反应 | 微动作（脚趾蜷缩 / 脊背僵硬 / 瞳孔震颤 / 汗水滑落）+ 非自愿反馈（痉挛 / 失禁 / 压不住的笑或哭腔） | 只写「她很难受」 |
| ③ 破碎语言 | 断断续续的求饶、无意义呢喃、被逼出的尖叫；拟声与动作同步 | 长篇完整的对白 |
| ④ 心理/第三方 | 受方：理智与本能的拉锯；攻方：猎物观察的满足与预判；环境：镜面倒影 / 监视画面 / 空气的粘稠感 | 全篇无视角切换 |

## 2. 感官层次（触觉起手，向其余感官延伸）

- **触觉**（主轴）：冰冷 / 湿润 / 酥麻 / 电击般的刺。
- **视觉**：潮红、透明、痉挛、器物反光。
- **听觉**：粘稠声、机械音、呼吸的断续。
- **嗅觉**（补充层）：汗、消毒水、皮革、潮湿空气——用于加深临场，不宜每段都用。
- **对比手法**：机械的冰冷与非人道 × 身体的柔软与脆弱，冲突本身即是张力来源。

## 3. 旁白与对白

### 3.1 旁白
- 感官聚焦，不写抽象评价。
- 不抢戏：旁白服务于当下动作与反应，不插入作者议论。

### 3.2 对白
- **受方**：多短句、多语气词（呜 / 哈啊），体现刺激下的理智崩解。
- **攻方**：语气随人物设定（温柔 / 冷酷 / 戏谑），保持角色一致性，不与 `novel.kb` 第 2 章冲突。

## 4. 拟声词总则（细则见 S3）

本段只给**使用原则**，词库与分阶段规范走 `themes/tk.md` 的 S3/S4：

1. 拟声词必须与动作**同步**，用于增强打击感或湿润感，不独立成段。
2. 按情境分类取用：湿润类 / 机械物理类 / 人声生理类 / 符号快感类。
3. **密度纪律**：与原文字数密度相近，不过度堆叠；忍耐期简短克制，极限期才可大量堆叠。
4. **防过拟合**：词库是参考规律而非模板，**严禁直接复制示例文本**；同类场景在不同章节应有自然差异。
5. 符号系统（`♡` / `❤` / `～`）的编码规则以 `decision-log §十八` 与 S3-symbols 段为准，本段不复述。

## 5. 瘙痒与笑声专项原则

**核心**：突出「生理性背叛」与「不可抗拒的崩溃」。笑声不是愉悦的，而是痛苦、绝望与生理本能的混合产物。

### 5.1 三层递进（与 S3 笑声五阶段对齐，此处只给原则）

| 层 | 特征 | 描写重心 |
|---|---|---|
| 初期（忍耐期） | 断续漏笑、闷哼、咬牙挤出 | 克制、少量、含压抑感 |
| 中期（爆发期） | 失控狂笑、横膈膜痉挛 | 密度上升、节奏加快 |
| 后期（崩溃期） | 破碎甜腻的大笑、哭腔求饶、缺氧绝叫 | 语言崩解、符号/堆叠 |

### 5.2 生理细节三组

- **呼吸系统**：横膈膜剧烈痉挛、从肺里榨取氧气、缺氧涨红、急促换气。
- **肌肉反应**：脊背如弓绷紧、脚趾蜷缩、腰部蛇形扭动、全身阵阵弹跳。
- **分泌物**：笑到眼泪直流、汗水打湿鬓角、过度刺激下的涎液或失禁。

### 5.3 心理与氛围

- **理智崩溃**：写「维持尊严 → 支离破碎」的过程，不给瞬间的结论。
- **感官过载**：思维被笑声填满、恍惚、感觉自己不再是自己。
- **凄绝感**：用词上强调痛苦与无助并存，避免写成纯粹的欢愉。

### 5.4 瘙痒原则（三条硬判据）

1. **不可逃避感**：受方必须有过「试图逃 / 试图忍」的动作，失败才成立。
2. **生理性背叛**：身体反应与主观意愿相反（求饶的同时身体在迎合）。
3. **权力不对等**：谁掌握节奏必须清楚，不能写成对等的嬉闹。
