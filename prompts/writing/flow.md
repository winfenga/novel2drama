# S1 · 长篇 R18 小说创作流程骨架（novel_nsfw）

> 来源：`docs/excerpts/15_TK写作SKILL_全文.txt` L51-164（S1 段）。
> 本文件只承载 **S1 = 五阶段工作流 + novel.kb 结构 + 创作准则 A/B**。
> S3（拟声词规则）/ S4（场景词库）在 `prompts/themes/tk.md`；S2 在 `conventions.md`；
> S5 在 `punctuation.md`；S6 在 `materials.md`。
> 注入时机见 `apps/core/src/promptlib/retrieval.ts`：draft → [S1]；fill → [S1 + S3/S4]；polish → [S2, S5]。

**总原则**：首先这是一篇逻辑严谨的小说，其次才是 R18 的情感小说。
策略 = **逻辑先行 / 色情留白 / 专项填充**。

## 1. 五阶段流程

| # | 阶段 | 输入 | 动作 | 输出 |
|---|---|---|---|---|
| 1 | 需求澄清与初始化 `clarify` | 初步想法/主题 | 逐一提问 + 人物画像 + 素材推选 | 项目目录 + 初始 `novel.kb` |
| 2 | 大纲细化与章节规划 `outline` | 澄清结果 | 起承转合 → 逐章拆解（剧情/基调/NSFW 爆发点） | 更新 `novel.kb` |
| 3 | 逻辑优先的初稿 `draft` | `novel.kb` | 正常叙事 + 色情留白 + 占位符标记 | 含占位符的逻辑初稿 |
| 4 | NSFW 场景专项实现 `fill` | 初稿占位符 | 子任务确认 → 素材检索 → 深度描写 → 衔接优化 | 填充完整的章节 |
| 5 | 整体润色与一致性 `polish` | 成稿 | 文学性提升 + 一致性校验 | 最终定稿 |

### 1.1 阶段一：澄清（硬约束）

- **逐一提问，严禁一次性抛出所有问题。** 每轮只推进一个问题，得到回答后再问下一个。
- 第一组：故事背景（时间 / 地点 / 世界观设定），随后核心冲突与情感基调。
- 第二组（背景确认后才进入）：人物外貌与性格 → 人物 NSFW 属性（敏感点 / 性癖 / BDSM 角色 / 生理极限）。
- 第三组：素材推选——向用户推选设定模板（触手 / 机械 / 状态变更等），由用户确认采用哪一类。

### 1.2 阶段二：大纲与章节规划

- 与用户讨论并确定起承转合。
- 逐章明确：剧情走向 / 情感基调 / 预期 NSFW 爆发点。
- 确认后写入 `novel.kb` 第 3、4 章。

### 1.3 阶段三：初稿（逻辑优先）

- 只写剧情推进、环境描写、人物对话。
- **遇到调教或色情场景，严禁直接编写细节**，改为占位符留白：`[NSFW: 场景描述]`。
- 占位符描述必须写清「谁 / 做什么 / 强度 / 场合」四要素，供阶段四独立成子任务。

### 1.4 阶段四：场景专项实现

每个占位符 = 一个独立的「情感小故事」子任务，按顺序：
1. **需求确认**：编写前必须与用户交互确认（调教手段 / 角色心理状态 / 快感程度）。
2. **素材检索**：按类别取 `body/` `machine/` `tentacle/` `status/`。
3. **深度描写**：生理反应 + 心理博弈 + 感官细节。
4. **衔接优化**：填充后与上下文逻辑、语气必须咬合。

### 1.5 阶段五：润色

- 文学性提升：优化词汇、增加色气感、剔除学术词汇（走 `glossary.md` 的修正表）。
- 一致性校验：人物性格 / 设定 / 术语与 `novel.kb` 对齐。

## 2. `novel.kb` 结构

**严禁 AI 对话输出**：写入 `novel.kb` 时不许有任何开场白、解释性文字或协议头
（如「好的，这是为您构建的知识库…」）。文件内容必须从 YAML Front Matter 或一级标题直接开始。

```markdown
---
project: [小说名称]
last_updated: [YYYY-MM-DD]
status: [Drafting/Filling/Polishing]
---

# Novel Knowledge Base: [小说名称]

## 1. 世界观与背景 (World Building)
- 时间/地点
- 核心设定（如：魔法体系、社会等级）

## 2. 角色档案 (Character Profiles)
- [角色名]：外貌 / 性格；NSFW 属性（敏感点、性癖、倾向）；关系网

## 3. 故事大纲 (Story Outline)
- 核心冲突
- 结局走向

## 4. 章节规划 (Chapter Plan)
- [ ] 第一章：[标题] —— 剧情；NSFW 留白点
- [ ] 第二章：[标题] —— …

## 5. 术语与描写偏好 (Glossary & Preferences)
- 特定称谓 / 禁用词汇 / 推荐词汇
```

## 3. 创作准则 A：逻辑严谨性与去廉价化

- **拒绝廉价色情**：避免机械化动作堆砌与重复词汇；色情服务于人物关系与剧情压力，而非器官描写。
- **剧情驱动**：每一项 NSFW 行为都要有合理剧情驱动，人物行为逻辑必须符合已定性格。
- **仪式感与张力**：强调权力不对等与心理博弈，用环境氛围提升质感。

## 4. 创作准则 B：深度交织描写

- **多维穿插**：每段同时交织 4 层——调教者行为 / 被调教者生理反应 / 破碎语言 / 瞬时心理活动。
- **感官层次**：从触觉延伸至视觉、听觉、嗅觉，构建全向临场感。
- **瘙痒专项**：突出「不可逃避感」与「生理性背叛」（身体求饶、理智崩溃）。

## 5. 素材库使用纪律

- 写 NSFW 场景前必须查对应类别的 `elements.md` 与 `examples.md`。
- **严禁直接复制素材**，必须按当前剧情本土化适配。
- 素材库只存抽象设定，不含任何具体作品名/角色名（见 `materials.md`）。
