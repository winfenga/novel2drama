# S6 · 素材库指南（目录结构 / 去作品化纪律 / 检索规则）

> 来源：`docs/excerpts/15_TK写作SKILL_全文.txt` L1448-1538（S6 段）。
> 目录形制对齐 `docs/m101314-spec.md` §3.3：`MaterialCategory = "body" | "machine" | "tentacle" | "status"`。
> 只回答「库长什么样、怎么建、怎么检索、什么不能放」；不含任何示例段落。
> 词库与拟声词在 `prompts/themes/tk.md`（S3/S4），本文件不重复词表。

## 1. 定位与边界

| 项 | 规定 |
|---|---|
| 服务对象 | 阶段四 `fill` 的素材检索；按标签命中少数条，不整库注入 |
| 承载 | 库的**组织形式**：目录、条目结构、标签、检索、收录判据 |
| 不承载 | 词表（→ `themes/tk.md`）、描写规范（→ `conventions.md`）、标点（→ `punctuation.md`）、项目设定（→ `novel.kb`） |

本文件写「库的架子」，不写「库里的肉」。

## 2. 目录结构

库根 `.claude/nsfw/`，按 项目 → 用户 → 内置 三级覆盖查找。四类素材，每类一对文件：`elements.md`（设定模板）+ `examples.md`（示例段落）。

```
.claude/nsfw/
├── body/       # 身体 / 通用；elements.md + examples.md
├── machine/    # 机械；elements.md + examples.md
├── tentacle/   # 触手；elements.md + examples.md
└── status/     # 状态变更；elements.md + examples.md
```

`body` 是唯一带子文件的类，按宿主再分四组、**每组一对**：`common`/`common_examples`、`female`/`female_examples`、`male`/`male_examples`、`special`/`special_examples`。

### 2.1 两个文件的分工（硬边界）

| 文件 | 存什么 | 禁止存什么 |
|---|---|---|
| `elements.md` | 设定模板：核心要素 + 特性 + 适用条件 + 禁忌 | 成品描写段落、成段对白 |
| `examples.md` | 手法骨架：触发条件 → 感官通道 → 反应层次 → 收束（可留占位符） | 逐字抄录的原文、露骨细节 |

判据：前者答「这设定是什么、能不能用」，后者答「这段怎么组织」；两者都不答「原文长什么样」。

## 3. ★ 去作品化纪律

素材库是跨项目复用资产：带上某部作品的身份信息，它就不可复用，且把侵权与串味风险传给每本书。

### 3.1 三条禁令

| # | 禁令 | 覆盖范围 |
|---|---|---|
| 1 | 严禁作品名 | 书名、系列名、篇章名、外号、译名、缩写 |
| 2 | 严禁角色名与人物指代 | 全名、昵称、称号、代号、亲缘称谓 |
| 3 | 严禁专有名词 | 该作独创的装置名、组织名、地名、招式名、能力名、术语体系名 |

### 3.2 只许用功能位

| 允许（功能位） | 禁止（人格化身份） |
|---|---|
| 被调教者 / 受方 | 具体角色名、昵称、称号 |
| 调教者 / 施方 | 具体角色名、职务名、代号 |
| 旁观者 / 第三方群体 | 具体组织名、阵营名 |
| 装置 / 器物 / 介质 / 场地 | 作品独创的装置名、地名、机构名 |

### 3.3 判定标准（四问，全「否」才可入库）

1. 删掉这个词，读者还能看懂这条素材吗？——能，说明是可替换装饰，必须换。
2. 放进任何一本无关的书里，会让人立刻想起某部具体作品吗？——会即违规。
3. 该词是不是只有读过某部作品的人才懂？——是即违规。
4. 能否用通用名词或功能位等价替代？——能就替代，不留原词。

> 兜底：**能搜到的专名都算专名**。记不清出处但疑似来自单一作品的，一律抽象化。

### 3.4 改写三步

```
① 找到身份词 → ② 判它是否为设定必需 → ③ 换功能位 / 换通用名 / 直接删
```

| 命中情况 | 处理 |
|---|---|
| 人名、昵称、称号 | 换功能位（被调教者 / 调教者 / 旁观者） |
| 作品独创装置名 | 换通用类目名（如「拘束装置」「神经干涉系统」） |
| 组织名、地名、机构名 | 换场地类目名，或降级为「某场所」 |
| 招式名、能力名、术语体系名 | 只保留机制描述，丢弃命名 |
| 修饰性身份头衔 | 直接删，不影响语义 |

### 3.5 改写前后对比（只看名词层，不涉及任何描写）

| 位置 | 改写前（违规形态） | 改写后（合规形态） |
|---|---|---|
| 主体 | 某作主角名 | 「被调教者 A」 |
| 施方 | 某作反派名 | 「调教者」 |
| 装置 | 某作独创装置名 | 「箱型全封闭拘束装置」（类目名） |
| 能力 | 某作独创能力名 | 「感官反馈劫持」（机制描述） |
| 地点 | 某作虚构地名 | 「封闭实验设施」 |
| 体系 | 某作独创术语 | 「状态变更类设定」 |

### 3.6 校验与处置

| 项 | 规定 |
|---|---|
| 入口 | `materialLib.checkDeNovelized(entry): string[]`（契约 §3.3） |
| 行为 | **只报不改**：返回违规项，交人复核 |
| 闸门 | 返回非空即拒收；修完复验 |
| 常见漏网 | 译名与缩写、粉丝外号、作品内的计量单位与等级体系 |

## 4. 检索规则

### 4.1 条目结构

```ts
interface MaterialEntry { id: string; category: MaterialCategory; tags: string[]; body: string }
```

- `id`：稳定唯一，不含作品痕迹。
- `category`：四选一；不确定时不上库（宁缺勿错类）。
- `tags`：检索唯一入口，见 4.2。
- `body`：设定描述或手法骨架，**不含成品描写**。

### 4.2 标签体系

| 维度 | 取值来源 | 用途 |
|---|---|---|
| 类别 | `body` / `machine` / `tentacle` / `status` | 一级过滤，必填 |
| 场景类型 | `A` / `B` / `C1` / `C2`（对齐 `TkSceneType`） | 与 `tk.md` 的 S3/S4 口径一致 |
| 作用对象 | 通用部位名、通用装置类目 | 二级过滤 |
| 手法性质 | 拘束 / 诱导 / 档位变化 / 状态切换 | 对齐占位符要素 |
| 强度区间 | 轻 / 中 / 重 | 控制节奏，避免一路拉满 |

标签**至少要覆盖占位符四要素**（谁 / 做什么 / 强度 / 场合），否则检索必然落空。

### 4.3 命中与返回

| 项 | 规定 |
|---|---|
| 时机 | 阶段四 `fill`，每个占位符一次 |
| 签名 | `retrieveMaterials(lib, tags, limit?)` |
| 命中 | 按标签求交，**不做全文关键词匹配** |
| 返回量 | 只返回命中条目前 N 条（默认个位数），绝不整表塞进上下文 |
| 空结果 | 返回空并如实报「库中无匹配」，不许拿通用段落凑数 |
| 去重 | 同一 `id` 单次只出现一次；跨占位符复用需重新检索 |

> 反例（判不合格）：把整个 `examples.md` 读进上下文再挑——超预算，且污染文风一致性。

## 5. 与 S3 / S4 的边界

| 内容 | 归属 | 说明 |
|---|---|---|
| 拟声词、笑声阶段、符号体系、A/B/C 场景定义 | `prompts/themes/tk.md`（S3/S4） | **词表只在那边**；本文件不复制、不改写、不索引具体词 |
| 目录、条目、标签、检索、收录判据 | **本文件（S6）** | 只描述组织方式 |
| 描写公式与感官层次 | `conventions.md`（S2） | 本文件不承担写作规范 |
| 词汇修正与禁用词 | `glossary.md` | 本文件不列词 |
| 标点细则 | `punctuation.md`（S5） | 与素材库无关 |

**硬规则**：本文件出现任何具体词条、拟声写法或描写片段，即为越界——删除并指向 `themes/tk.md`。

## 6. 维护清单

- **色情导向**：只收直接服务 NSFW 情节的设定；纯战斗技能、非感官类超能力不收。
- **按作用对象分类**：按 `tentacle` / `machine` / `status` / `body` 落位，不按来源作品落位。
- **更新顺序**：先补 `examples.md` 的手法骨架，再据新玩法补 `elements.md`。
- **定期清理**：重复合并、低质剔除、失效下线；同步更新 `id` 引用。
- **术语一致性**：全库统一「快感」= 愉悦体验，「感官」= 全部生理/心理体验。
- **收工标准**：§3.3 四问 + §3.6 校验，两项都过。
