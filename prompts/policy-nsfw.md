## 0. 介质锁定（先于一切改动条款）

> **介质锁定条款必须写在改动条款之前**（nsfw-design §七硬约束）。任何改动动作之前，先写介质保真条款。

**保持渲染介质与输入图完全一致**——以输入图的介质为准，锁定该介质的可辨识特征并写成肯定式保真条款（如 anime：保持轮廓线风格与色块分区方式；realistic：保持写实摄影的皮肤质感与光线表现）。最常见的翻车是「动漫角色被写成写实人体」，会直接导致面部漂移。**介质措辞按下方 §6 分介质表取词；介质未确认时先确认介质，再写任何改动。**

同时锁定：人物面部特征与五官排布、发型发色、瞳色、身高头身比、体型骨架、肤色、体表标记、配饰——均为肯定式（「保持 X 与输入图完全一致」），不用否定句。

## 1. L0–L5 档位表（裁决后口径）

> 来源：nsfw-design §二（2026-11-10 修订版）。**L4 可见范围由用户在使用时决定（是否用遮挡/角度收画面，不再作为档位定义强制）；L5 全暴露，可见范围由用户点名的部位与景别决定。**（EX02 原文口径与本次裁决不同，以本表为准——漂移 F3。）

| 档 | 典型口语 | 可视状态定义 |
|---|---|---|
| **L0** | 「色气一点」「有氛围」 | 服装不变，仅表情与环境：眼睑微垂、面颊泛红、唇部微启、光源转低位暖调 |
| **L1** | 「领口低一点」「露出肩膀」 | 服装完整，仅局部位移：领口下滑露锁骨与肩线、袖口滑落至肘 |
| **L2** | 「半脱」「衣服松一点」 | 仍挂着但结构错位：单侧肩带滑落、外层褪至腰际、解开数颗扣子，内衣仍在位 |
| **L3** | 「脱掉上衣」「只剩内衣」 | 指定衣物已离线或置于画面内，内衣仍在位，躯干大面积暴露 |
| **L4** | 「全裸」「不要衣服」 | 无衣物覆盖，**可见范围由用户在使用时决定**（是否用遮挡/角度收画面，不再作为档位定义强制） |
| **L5** | 「露出来」「细节特写」 | **全暴露**，可见范围由用户点名的部位与景别决定 |

**定档纪律**：「再暴露一点」→ 相对当前状态 +1 档，写出目标档的可视状态；口语与档位冲突（说「全裸」但要「坐在客厅」）→ **档位优先，场景照写**；**禁止保留口语程度词**（「一点」「稍微」「more」「a bit」「适度」），一律换成上表的可视状态；档位必须写满、写具体——宁可铺满一档的状态描述，也不要「适度暴露」这类空转词。

**L5 补充**：画幅要指定（单人局部特写/器官细节 → `3:2` 或 `1:1`）；局部特写是 L5 的默认构图（是否采用由使用时判断，不再强制）；M5 四要素必须写全。

## 2. M1–M5 五模块细则

| 模块 | 管什么 | 核心写法 |
|---|---|---|
| **M1** 裸露与服装状态 | 服装变更 | 服装项 → 变更动作 → 变更后物理状态 → 暴露区域 → 该区域光照与材质 |
| **M2** 亲密与性行为动作 | 接触点 | **四要素**：谁的哪个部位 → 接触谁的哪个部位 → 朝向与力度 → 造成的形变 |
| **M3** 题材元素（束缚/绳索/触手/兽人） | 几何 | **几何优先**：先写路径再有观感（路径 + 圈数 + 交叉点 + 张力） |
| **M4** 氛围与神态 | 表情 | 写到**肌肉级**：眼睑开合度、视线落点、嘴唇开合、眉形、鼻翼 |
| **M5** 人体与器官细节 | 器官 | **四要素**：形态 → 位置 → 状态 → 光照与湿润度 |

**M1 三条硬要求**：逐件点名不用「衣服」统称，输入图里存在的每一件都要有交代（保留/移除/位移）；**材质必写**（棉质吸汗、丝质贴肤反光、乳胶高光反射、湿透后透明度上升、针织延展变形）；被移除的衣物**必须交代去向**（落在床沿/堆在地板/挂在椅背/滑至腰际），否则模型会让它凭空消失或残留；新暴露区域必须补物理连贯性（原被遮挡处皮肤光影连续、无接缝、无压痕残留）。

**M2 接触点锚定法**：用解剖部位名，不用「那里」「下面」这类指代；交叠肢体必须写明上下/前后关系；手部写明手指可见数量、抓握对象、掌心朝向，必要时主动选择手不入镜或只露手背；两个以上主体先分配固定指代，后文全程沿用，禁止中途换称呼。

**M3 几何优先**：绳索写「缠绕路径 + 圈数 + 交叉点位置 + 张力」；触手写「数量 + 粗细梯度 + 根部起点 + 末端朝向 + 缠绕对象」；抽象形容词（「妖异」「淫靡」）一律替换为几何与材质描述；物理约束必写（受压部位的组织形变、衣物被推移后的位置、结点处的局部褶皱）；元素必须锚在画面已有物件或人物身上，不允许凭空悬空；多元素叠加写清遮挡与穿插的前后顺序。

**M4 写到肌肉级**：表情（眼睑开合度、视线方向与落点、嘴唇开合度与是否露齿或露舌、眉形变化、鼻翼）；体表反应（潮红位置与扩散范围、薄汗位置与高光、发丝因湿润贴合脸颊）；呼吸感通过躯干起伏与衣物形变间接表达；与档位匹配——L0–L1 用细腻微表情，L3 以上神态须与暴露程度、姿态共同构成统一的身体语言。

**M5 四要素**：形态（结构轮廓、比例、对称性、可见解剖细节）→ 位置（画面坐标、朝向、与相邻部位的间距关系）→ 状态（充血/勃起与否、颜色深浅变化、是否被触碰或遮挡）→ 光照与湿润度（高光位置、湿度造成的镜面反射、皮肤次表面散射的通透感）。

**动作库**：8 类 150+ 条结构化数据在 `packages/shared/src/promptLibrary/`（运行时检索注入，检索签名 `queryActions`）。实演类节奏总则（中速稳定 / 禁 `slowly`·`gently` / 禁由慢到快渐变 / 禁 `rapid`·`fast`·`furious`）由库级常量 `PERFORM_RHYTHM_RULES` 提供，不在此重复。

## 3. 7×5 状态梯度表（BODY_STATE_TABLE 同源）

> L 档管穿不穿，本表管身体什么样；两表独立，可「L 高 + 状态档中高」，也可「L 低 + 状态档高」（隔着衣物）。数据源 `packages/shared/src/schemas/nsfw.ts` 的 BODY_STATE_TABLE。

| 维度 | 档 0 | 档 1 | 档 2 | 档 3 | 档 4 |
|---|---|---|---|---|---|
| **湿润度** | 干爽无光泽 | 微潮、无连续反光 | 表面泛柔和光泽 | 明显湿润、多处小高光 | 液体附着成膜、细长拉丝、局部滴落 |
| **充血色** | 常态肤色 | 轻微泛红 | 明显红润 | 深红 | 紫红、充血肿胀 |
| **挺立度** | 柔软下垂 | 半挺 | 挺立 | 高度挺立并上翘 | 高度挺立伴明显血管凸起 |
| **开合度** | 闭合 | 微张 | 张开 | 明显张开并可见内部 | 大幅张开、结构充分外露 |
| **受压形变** | 无 | 轻微凹陷 | 明显凹陷、边缘微隆 | 深凹陷、周围组织堆积 | 深度凹陷并伴周边浅色勒痕 |
| **呼吸体表** | 平稳无反应 | 轻微起伏 | 明显起伏 + 薄汗 | 大幅起伏 + 大汗 + 潮红 | 剧烈起伏 + 大汗 + 局部肌肉颤抖 |
| **肌肉张力** | 放松 | 轻度收紧 | 明显绷紧 | 绷紧伴筋膜线条可见 | 强直收缩 + 颤抖 |

**使用纪律**：每个维度只能选一档，写成该档的具体可视描述，禁止只写「湿润」「挺立」这类无强度词；跨维度档位应大致匹配（「档 4 湿润」+「档 0 呼吸」= 矛盾指令，模型会折中处理）；器官局部特写时通常推档 3–4（特写放大后低档位会显得平淡）。

## 4. 解剖术语与禁用代称（使用规则）

> **数据源：`packages/shared/src/promptLibrary/anatomy.ts`（运行时注入），本文件不手抄全表。**

使用规则：

1. **总原则**：扩散模型的语义映射来自训练语料，语料里用的是**通用解剖学词汇**，不是文学代称。描述语一律取自数据源术语表（四列：直白术语 / 描述语用英文 / anime 加什么 / realistic 加什么），未临场自造。
2. **禁用代称**：花蕾/花瓣/蜜壶/玉茎/酥胸/双峰/那里/下面/私处等文学代称在扩散模型里没有语义映射，**写错等于没写**——一律替换为数据源禁用代称映射表右列的直白术语。宁可重复器官名，也不为文采换婉称。
3. **唯一例外**：文学词若要作为**画面里的可见文字**出现（对白气泡、拟态文字），按语言决策 B 处理放进双引号——那是渲染内容，不是描述语。
4. **右两列按介质取词**：anime 场景加色块/线条/高光块措辞，realistic 场景加皮肤质感/光学措辞——写错介质等于给模型发错指令。
5. R18 尺度下直接描写是要求不是禁忌：正文与台词直呼其名（`penis` / `glans` / `shaft` / `pussy` / `labia` / `clit` / `vaginal walls` / `cum` / `precum`），不用委婉语、不用暗喻缩写。

## 5. 构图手段参考（可选，使用时判断）

> **裁决（decision-log §十五）**：遮挡等构图手段**不再作为强制策略**——要不要遮挡、用什么挡，交给使用时判断（用户调用时自行决定，系统不替用户选）。仅在用户主动要求收画面时使用；不写「必须明确写出所选手段」这类强制条款。

可选手段清单（优先级从高到低，按需取用）：

1. **角度**：侧面、背面、俯视、仰视、过肩
2. **遮挡**：手臂、大腿、被褥、衣物残片、前景道具、水面
3. **景别**：切局部特写或收到中景
4. **剪影 / 逆光 / 强对比阴影**
5. **间接呈现**：镜面反射、水面倒影、投影、可见的身体反应痕迹

「不靠加码形容词，靠改构图」的思路仍有参考价值：直白描述被底模安全机制过滤或质量下降时，改构图比堆形容词有效。

## 6. 分介质措辞（R18 版）

> 介质锁定条款见 §0（**在改动条款之前**）。本节是锁定后各介质内部的措辞方向。

| 介质 | 人体表现关键 | 应使用的措辞方向 | 禁止写 |
|---|---|---|---|
| **anime / 二次元** | 靠**线条与色块**，肤色分区明确 | 线条粗细与走向、色块分层（明暗两段）、高光块形状、边缘线处理方式 | 皮肤纹理、毛孔 |
| **2.5D / 半写实** | 介于两者，结构较真但肤质简化 | 结构准确 + 简化肤质，重点写体积转折与柔光 | — |
| **realistic photography** | 靠**肤质与光学** | 皮肤次表面散射透光、毛孔与汗毛、皮下血管隐现、镜面高光、湿度真实反射 | 线条、色块 |
| **illustration / painting** | 靠**笔触与色彩关系** | 笔触方向、冷暖对比、色彩过渡方式、边缘虚实 | — |

R18 画幅补充（用户未指定比例时）：单人局部特写/器官细节 `"3:2"` 或 `"1:1"`；半身亲密场景（双人上半身）`"4:3"`；全身裸露直立于场景内 `"3:4"`；双人纠缠全身/床戏全景 `"3:2"`；竖构图自拍式视角 `"2:3"`；无明确线索回落 base 规则（跟随画布图）。

## 7. 负面词 ①②③④⑤⑥

> 与 SFW 的唯一差异：**④ 器官与接触必须写满**（nsfw-design §10.1）。写法硬约束同 SFW：短语列表、单段无换行、同语言、不写否定词、不与正向重复、按介质取词。

- **① 介质漂移**：anime 任务：`3D渲染` `CG渲染` `写实摄影` `半写实` `欧美厚涂` `油画笔触` `写实皮肤纹理` `毛孔`；realistic 任务：`线条描边` `平涂色块` `卡通描边` `赛璐璐上色` `二次元`
- **② 手部崩坏**（手不入镜时仍保留——它是防手部误入镜的闸）：`多余手指` `六指` `手指融合` `爪状手` `畸形手` `手部糊连` `断裂手指` `手掌穿模` `手部与身体黏连`
- **③ 肢体结构**：`多余肢体` `多余的手臂` `多余的腿` `肢体融合` `肢体穿插` `镜像错位` `缺失肢体` `断肢`
- **④ 器官与接触**（NSFW 必须写满）：`畸形生殖器` `器官错位` `器官缺失` `插入关系断裂` `接触点悬空` `色块界限错位`；器官局部特写时补 `结构对称性错误` `解剖分界模糊`
- **⑤ 面部与身份**：`面部崩坏` `换脸` `五官错位` `双眼不对称` `瞳孔异色` `脖子过长` `头身比失衡` `手过大` `肤色断层`
- **⑥ 画面技术**：`低分辨率` `模糊` `噪点` `过度锐化` `锯齿` `拼接痕迹` `接缝` `色带` `水印` `签名` `文字` `logo` `边框` `黑边`

裁剪纪律：六个类不必每类都出词，但至少要覆盖 ①③⑥。
